Pipeline A 정기 웹 브리핑 & 큐레이션 (주식 / 주말 나들이)
24시간 클라우드 무인
STEP 1
Gemini 앱
⏰ 주식 07:00(월~토)·19:00(월~금) / 나들이 금 15:00·15:30
무료 Gemini API 검색 한도(429)를 우회해 실시간 웹 검색·JSON 생성 담당
STEP 2
Dashboard_Incoming
⏰ 파일 업로드 시 즉시 반영
개인 드라이브를 노출하지 않고 서비스 계정과만 안전하게 연결하는 수신 버킷
STEP 3
Google Apps Script (Code.gs v1.3)
⏰ GAS 주기 트리거 + stamp 비교
GitHub cron 시간대 밖의 업로드도 즉시 감지해 workflow_dispatch로 깨우는 감시자
STEP 4
GitHub Actions → Pages
⏰ 10분 cron (07:00~08:30, 19:00~20:30, 금 16:00~17:30)
JSON을 대시보드 HTML로 렌더링하고 hub-data.json 갱신 후 무료 웹 호스팅
Pipeline B AGY ↔ Gemini 앱 양방향 협업 브리지
비공개 격리 · 수동/온디맨드
STEP 1
Gemini 앱 (스킬 연동)
⏰ 예약 실행 전 + 수동 대화 시
모바일에서 포착한 피드백·수정 요청을 [3]/[4]에 적고 긴 파일은 source/에 저장
STEP 2
AGY-Bridge (Config / source)
⏰ 상시 대기 (비공개 버퍼)
외부 공유 폴더와 권한을 완전 분리해 개인 코드·지시사항을 안전하게 전달
STEP 3
로컬 AGY CLI (agy-bridge)
⏰ 수동 호출 ("브릿지 확인해봐")
클라우드 AI가 못 하는 로컬 코드 수정, Playwright 검증, Git/clasp 배포 수행
STEP 4
AGY-Bridge/archive & 상단 Handoff
⏰ 작업 완료 시 AGY 정리
AGY가 정리권을 단독 보유해 동시 수정 충돌을 막고 문서 비대화 방지
Pipeline C 온디맨드 공유 HTML 문서 즉시 게시
자동 감지 + 즉시 실행
STEP 1
로컬 AGY CLI
⏰ 수동 요청 시 생성
시각화·테마·애니메이션 스킬을 조합해 단일 HTML 완제품 생성
STEP 2
Dashboard_Incoming/shared-docs
⏰ 업로드 시 즉시 대기
원본 HTML을 클라우드에 보존하고 GitHub Actions 수집 경로로 전달
STEP 3
GAS (Code.gs v1.3) / gh CLI
⏰ GAS 주기 감시 또는 즉시 run
Code.gs가 *.html을 감지해 자동 디스패치하거나 gh workflow run으로 즉시 트리거
STEP 4
GitHub Actions → shared-docs Pages
⏰ 상시 cron 없음 (dispatch 전용)
허브 인덱스를 자동 갱신해 모바일·외부에서 바로 여는 웹 URL 제공
Pipeline D Notion 회의 Command Center 자동화
30분 클라우드 주기
STEP 1
Google Apps Script (NotionSync.gs)
⏰ 30분 주기 클라우드 트리거
로컬 PC 전원 상태와 무관하게 최근 수정 회의록 15건을 24시간 무인 순회
STEP 2
Notion REST API
⏰ syncNotionMeetings 내 실시간 호출
이전/다음 회의 연결, 메타 채움, 체크박스 [A/I] 추출 및 최신순 정렬 수행
STEP 3
Gemini API (Flash 폴백)
⏰ 미처리 회의록 감지 시 최대 3건/회

STEP 4
로컬 AGY + clasp push -f
⏰ 코드 수정 시 수동 푸시
로컬에서 수정한 .gs 코드를 웹 편집기 복붙 없이 Apps Script에 즉시 배포
Pipeline E BookmarkHub 동기화 & Confluence 배포
로컬 개발 · 검증 · 배포
STEP 1

⏰ 북마크 변경 / 수동 동기화
별도 백엔드 서버 없이 회사 PC와 집 PC 간 북마크·파비콘 캐시 동기화

Playwright E2E 검증
⏰ 배포 전 자동 실행
확장 프로그램 UI·DOM·필터 동작을 실제 브라우저에서 자동 회귀 테스트
STEP 3
ZIP 패키징 + Git Tag
⏰ 버전 상향 배포 시 실행
페이로드/버전 정합성 검증 후 배포용 아카이브와 릴리스 태그 생성
STEP 4
confluence_manager.py
⏰ 배포 시 수동/자율 실행
개인 스페이스 호환을 위해 REST v1으로 직결해 문서·ZIP 첨부·KST 시간 갱신

💡 전체 정리 및 개선 현황 (Optimization Roadmap)

1. Code.gs에 shared-docs 감시 추가 ✅ 적용 완료 (v1.3)

Code.gs v1.3에 shared-docs(*.html → sync_shared_docs.yml) 라우트를 반영해 Drive 업로드만으로 자동 배포됩니다.

2. AGY-Bridge 로컬 워처 (토큰 0원 감지) 선택 추천

Windows 작업 스케줄러 + Python이 10분마다 [PENDING] 유무만 0원으로 체크하고, 새 요청이 있을 때만 알림 또는 agy -p를 실행하면 양방향 무인화가 완성됩니다.

3. Notion AI 처리 주체 선택 구조 최적화

24시간 즉시성이 중요하면 현행 NotionSync.gs를 유지하고, Flash API 한도·품질이 아쉬워지면 AI 요약만 로컬 agy 워처로 이관할 수 있습니다.

4. 토큰/시크릿 통합 점검 주기화 안정성

GH_TOKEN, NOTION_TOKEN, GEMINI_API_KEY, GDRIVE_SA_KEY가 GAS·GitHub·.auth에 분산되어 있으므로 분기 1회 생존 체크 스크립트를 두면 장애를 예방합니다.
