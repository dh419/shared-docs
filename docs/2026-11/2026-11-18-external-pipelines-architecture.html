🔗 파이프라인별 순서 · 실행 주기 · 도구 선정 이유

Pipeline A 정기 웹 브리핑 & 큐레이션 (주식 / 주말 나들이)
24시간 클라우드 무인
STEP 1
Gemini 앱
⏰ 주식 07:00(월~토)·19:00(월~금) / 나들이 금 15:00·15:30
무료 Gemini API 검색 한도(429)를 우회해 실시간 웹 검색·JSON 생성 담당
STEP 2
Dashboard_Incoming
⏰ 파일 업로드 시 즉시 반영
개인 드라이브를 노출하지 않고 서비스 계정과만 안전하게 연결하는 수신 버킷
STEP 3
Google Apps Script (Code.gs v1.3)
⏰ GAS 주기 트리거 + stamp 비교
GitHub cron 시간대 밖의 업로드도 즉시 감지해 workflow_dispatch로 깨우는 감시자
STEP 4
GitHub Actions → Pages
⏰ 10분 cron (07:00~08:30, 19:00~20:30, 금 16:00~17:30)
JSON을 대시보드 HTML로 렌더링하고 hub-data.json 갱신 후 무료 웹 호스팅
Pipeline B AGY ↔ Gemini 앱 양방향 협업 브리지
비공개 격리 · 수동/온디맨드
STEP 1
Gemini 앱 (스킬 연동)
⏰ 예약 실행 전 + 수동 대화 시
모바일에서 포착한 피드백·수정 요청을 [3]/[4]에 적고 긴 파일은 source/에 저장
STEP 2
AGY-Bridge (Config / source)
⏰ 상시 대기 (비공개 버퍼)
외부 공유 폴더와 권한을 완전 분리해 개인 코드·지시사항을 안전하게 전달
STEP 3
로컬 AGY CLI (agy-bridge)
⏰ 수동 호출 ("브릿지 확인해봐")
클라우드 AI가 못 하는 로컬 코드 수정, Playwright 검증, Git/clasp 배포 수행
STEP 4
AGY-Bridge/archive & 상단 Handoff
⏰ 작업 완료 시 AGY 정리
AGY가 정리권을 단독 보유해 동시 수정 충돌을 막고 문서 비대화 방지
Pipeline C 온디맨드 공유 HTML 문서 즉시 게시
자동 감지 + 즉시 실행
STEP 1
로컬 AGY CLI
⏰ 수동 요청 시 생성
시각화·테마·애니메이션 스킬을 조합해 단일 HTML 완제품 생성
STEP 2
Dashboard_Incoming/shared-docs
⏰ 업로드 시 즉시 대기
원본 HTML을 클라우드에 보존하고 GitHub Actions 수집 경로로 전달
STEP 3
GAS (Code.gs v1.3) / gh CLI
⏰ GAS 주기 감시 또는 즉시 run
Code.gs가 *.html을 감지해 자동 디스패치하거나 gh workflow run으로 즉시 트리거
STEP 4
GitHub Actions → shared-docs Pages
⏰ 상시 cron 없음 (dispatch 전용)
허브 인덱스를 자동 갱신해 모바일·외부에서 바로 여는 웹 URL 제공
Pipeline D Notion 회의 Command Center 양방향 자동화
30분 클라우드 · 15분 수정 유예
STEP 1
Google Apps Script (NotionSync v1.11)
⏰ 30분 주기 트리거 (본문 15분 유예)
골격·회의링크·리마인드는 즉시, 요약·태그·[]/AI 추출은 15분 유예 후 유사도 중복방지 적용
STEP 2
Notion REST API + 댓글 양방향
⏰ 실행 시 페이지·블록·댓글 스레드 조회
15개 파트 배정, 결정=완료, 질문 댓글에 사용자 답글 시 재분석 후 [AI 처리 완료] 답글
STEP 3
Gemini API (Flash 폴백)
⏰ 미처리·수정·기준변경 시 최대 3건
V10Q 리더·NAND 약어 사전 기반 개조식 4~6줄 요약 및 미등록 약어 questions 도출
STEP 4
Notion-AI-Feedback ↔ AGY
⏰ 양방향 학습 (재푸시 불필요)
AI 질문을 source/ 문서에 누적 → AGY/사용자 확정 기준을 매 실행 시 자동 로드해 진화
Pipeline E 3종 크롬 컨트롤 · BookmarkHub · Confluence 배포
로컬 개발 · 브라우저 제어 · 배포
STEP 1
3종 크롬 컨트롤 라우팅
⏰ 작업별 최적 엔진 자동 선택
agent-browser(격리 고속) · browse(실제 크롬 19988) · Playwright(E2E/콘솔 검증)
STEP 2
BookmarkHub ↔ GitHub Gist
⏰ 북마크 변경 / 파비콘 웜업
도메인 파비콘 크롤링 + URL 단위 웜업으로 회사↔집 PC 북마크 동기화
STEP 3
ZIP 패키징 + Git Tag
⏰ 버전 상향 배포 시 실행
페이로드/버전 정합성 검증 후 배포용 아카이브와 릴리스 태그 생성
STEP 4
confluence_manager.py
⏰ 배포 시 수동/자율 실행
개인 스페이스 호환을 위해 REST v1으로 직결해 문서·ZIP 첨부·KST 시간 갱신
Pipeline F DOOKI 개인 위키 자동 적재 (모바일 Gemini 앱 ↔ AGY ↔ Notion)
업무 DB 분리 · 30분 무인 + 즉시
STEP 1
Gemini 앱 (@dooki-inbox)
⏰ 모바일/웹 자연어 메모
"두키에 적어줘" 발동 시 민감 원문을 마스킹해 DOOKI-Inbox 문서에 1줄 추가
STEP 2
AGY-Bridge/source/DOOKI-Inbox
⏰ 비공개 Docs 버퍼

STEP 3
DookiSync.gs + Gemini API
⏰ 30분 주기 자동 분류·적재
가족여행·차량/가전/월세·아이·구독·건강 등 8개 페이지로 자동 분류 후 인박스 정리
STEP 4
Notion DOOKI + AGY (dooki-personal-wiki)

영역(5종)·유형·즐겨찾기·인증(만료알림) 구조로 장기 유지·확장
